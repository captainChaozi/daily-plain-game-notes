# Daily Plain Game notes

Strategy notes and reference for the [Daily Plain Game](https://plaingame.fun/), a free browser estimation game: seven rounds a day, no sign-up. The closer you guess, the higher your plane climbs.

> Independent edition. Not affiliated with the original PlayPlain service.

## How a flight works
- Seven rounds per daily flight. Most ask you to **name** something close to a target value (a mountain near an elevation, a film near a running time); some ask for a **number** estimate.
- Each timed round lasts **30 seconds**; the first accepted answer is final.
- Name rounds: type a full name and pick from suggestions so it is accepted.
- Number rounds: ordinary numbers or shorthand like `2.5k`, `1.2 million`; check the interpretation before submitting.
- Skipped or timed-out rounds earn no accuracy points.

## Habits that help
1. **Read the unit.** Height is not length; theatrical runtime is not an extended cut.
2. **Anchor and adjust.** Start from a value you know and step toward the target.
3. **Get the scale right** before worrying about digits.
4. **Learn from reveals.** Keep surprising values as future anchors.
