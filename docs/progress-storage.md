# Daily Plain Game: where progress lives

How the [Daily Plain Game](https://plaingame.fun/) (seven rounds, 30 seconds each) stores your record. Source: [FAQ](https://plaingame.fun/faq) and [game modes](https://plaingame.fun/game-modes), last updated 2026-10-23.

## Stored locally in your browser

| Item | Stored | Notes |
|---|---|---|
| Completed flights | This browser | Not synced across devices |
| Daily streak | This browser | Built by finishing on consecutive days (America/New_York dates) |
| Badges and experience (XP) | This browser | Practice and past flights do not add XP |
| Preferences | This browser | |

No account is needed, and a website account does not synchronise flights across devices.

## What breaks your record

- Clearing site data or browser storage.
- Switching to another browser, profile or device.
- Private windows: if browser storage is unavailable the game may use temporary storage, which may not survive closing or refreshing the page.

## What does not affect it

| Action | Effect on streak / XP |
|---|---|
| Free flight practice, collections | None |
| Discovery (untimed) | None |
| [Past flights](https://plaingame.fun/past-flights) (last two weeks) | None, practice only |
| Reloading the daily | Same route for the date, not a new set |
| Friend challenge | Rival score is self-reported |

## Tips

- Use one browser for your daily flights if you care about the streak.
- The daily resets at midnight in New York: 04:00 UTC in daylight-saving time, 05:00 UTC in standard time.
