# Daily Plain Game: Golden Round reminder

Site: https://plaingame.fun/ · Scoring: https://plaingame.fun/scoring

Each seven-round Daily hides one **Golden Round**. Base score and Bullseye on that round are doubled. You learn which round it was only after answering.

Perfect path including the doubled round → 1,000 accuracy points.

Seven rounds = five name + two number. Modes: https://plaingame.fun/game-modes
