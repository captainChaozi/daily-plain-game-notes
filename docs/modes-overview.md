# Daily Plain Game modes at a glance

From [Plain Game modes](https://plaingame.fun/game-modes):

| Mode | What it is |
|---|---|
| Daily flight | One shared challenge: seven rounds (five name, two number) |
| Unlimited practice | Keep playing after the daily |
| Untimed flight | No clock, for learning scale |
| Same as a friend | Play the same seven questions as someone else |

All modes are free with no account. Start at [plaingame.fun](https://plaingame.fun/); rules in [how to play](https://plaingame.fun/how-to-play).

Maintained by the maker of plaingame.fun.
