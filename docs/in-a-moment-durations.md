# In a moment：时长合集速查（Fixed durations）

> 适用于 [Daily Plain Game](https://plaingame.fun/)（seven rounds：5 个命名回合 + 2 个数字回合）。合集信息来自站内 [Field guide](https://plaingame.fun/field-guide)，2026-11-03 核对。

**In a moment** 是命名回合使用的 20 个合集之一：固定时长，单位为秒；这里的“一年”指 365 天。共 16 个条目，最短为 One second（1 s），最长为 One common year（31,536,000 s）。

## 常用换算（自行验算即可）

| 时长 | 秒 |
|---|---:|
| 1 分钟 | 60 |
| 1 小时 | 3,600 |
| 1 天 | 86,400 |
| 1 周 | 604,800 |
| 365 天 | 31,536,000 |

以上是通用换算，用来定位量级；合集具体包含哪些条目以游戏为准。

## 为什么量级比精确值重要

Plain Game 按比值计分：`round(100 × exp(−2 × |ln(answer / target)|))`。答案是目标的 2 倍或 1/2，都约得 25 分；落在 1.01 倍以内为 Bullseye，额外 +25。详见 [计分说明](https://plaingame.fun/scoring)。

这个合集从 1 秒跨到 3 千多万秒，跨了 7 个数量级。先判断目标是“分钟级 / 天级 / 周级 / 年级”，再选名字，比纠结具体数值更有效。

## 练习方式

- 在练习里选择该合集，或用不计时的 Discovery（见 [Game modes](https://plaingame.fun/game-modes)）。
- 名字要选建议列表里的完整名称；未识别的名字不消耗回合，但计时继续。
