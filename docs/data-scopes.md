# Data scope and reference values

How the Daily Plain Game at [plaingame.fun](https://plaingame.fun/) treats its answer data, summarised from the [field guide](https://plaingame.fun/field-guide) and [sources](https://plaingame.fun/sources) pages.

## Size of the bank

| Item | Count |
|---|---|
| Collections | 20 |
| Answer entries | 497 |
| Number prompts | 90 |

## What the values are

- **Frozen reference figures**, not live statistics.
- Rounding, measurement scope and source dates can differ between entries.
- The full bank has not been independently verified item by item.
- Example scope note: "High places" uses elevation above sea level in rounded metres.

## Name rounds

A real-world object can exist without being in the game's answer list. The list is finite; it is not a live search of every possible answer.

## Same questions for everyone

Players on the same data version receive the same seven daily rounds. The reset is midnight in New York.

## If a value looks wrong

Check the unit and scope first (rounded metres, a particular year, a stated definition). If it still looks wrong, use the contact page to report it with the round and your source.
