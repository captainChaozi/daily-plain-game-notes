# Finish lines: standard race distances (Daily Plain Game study card)

The **Finish lines** collection in the [Daily Plain Game](https://plaingame.fun/) asks for standard named distances in metres. The [field guide](https://plaingame.fun/field-guide) lists 14 entries, from **60 metres (60)** to the **100 kilometre ultramarathon (100,000)**.

## Reference distances

| Distance | Metres |
|---|---|
| 60 m sprint | 60 |
| 100 m | 100 |
| 200 m | 200 |
| 400 m | 400 |
| 800 m | 800 |
| 1500 m | 1,500 |
| Mile | 1,609.344 |
| 5 km | 5,000 |
| 10 km | 10,000 |
| Half marathon | 21,097.5 |
| Marathon | 42,195 |
| 50 km | 50,000 |
| 100 km ultramarathon | 100,000 |

Standard values as study references; the game uses its own frozen figures and may not include every row.

## Traps

- A **mile** is not 1,600 m; it is about 1,609 m.
- The **marathon** is 42.195 km, so 42,195 m, not 42,000.
- A **half marathon** is half of that: about 21,098 m.

## Scoring reminder

Plain scores on ratios. Answering 40,000 for a marathon is a small miss; answering 4,000 is a big one.
